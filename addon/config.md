**Use the Settings dialog instead of editing this JSON.**

Open it from **Tools → Anki Explainer Settings…**, from the ⚙ button in the
Explainer panel, or with the **Config** button in the add-ons list (which opens
the dialog rather than this editor).

Your OpenRouter API key is never stored here. It lives on this computer only
(OS keyring when available, otherwise `user_files/secret.json`) and does not
sync through AnkiWeb.

If you do edit this JSON by hand, invalid values fall back to their defaults.
